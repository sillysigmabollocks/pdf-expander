# PDF Expander

Add a left or right writing margin to each PDF page. Review the finished file in the browser, then use **Share PDF** to send it to Goodnotes on iPad. PDF processing stays on your device.

## Publish on GitHub Pages

In **Settings → Pages**, choose **Deploy from a branch**, select **main** and **/ (root)**, then save.

## Dependencies

This version loads pdf-lib 1.17.1 and PDF.js 5.7.284 from jsDelivr. PDF files stay in the browser.
